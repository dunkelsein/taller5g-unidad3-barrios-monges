## Descripción del Proyecto

Este repositorio contiene la implementación en Python de algoritmos clásicos de rasterización de líneas utilizando la biblioteca Pillow (PIL) para la generación de composiciones gráficas bidimensionales:

1. **Ejercicio 1 (`ejercicio1_casa.py`):** Reutiliza el algoritmo **DDA** para construir una composición geométrica de una casa estilizada con sus elementos representativos (cuerpo, techo, puerta, ventanas, sol, línea de piso y humo de chimenea).
2. **Ejercicio 2 (`ejercicio2_roseta.py`):** Reutiliza el algoritmo de **Bresenham** para generar rosetas geométricas paramétricas con gradiente cromático continuo en espacio de color HSV, explorando variantes según el número de vértices ($N = 12, 24, 36$) y conexión entre puntos.
